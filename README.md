# ITIL Foundation Version 5 — Guía Personal

Guía web en español con términos clave en inglés para estudiar ITIL Foundation Version 5 desde cero.

## Enfoque

Esta guía es un manual de referencia, no un sitio de flashcards. Está pensada para entender conceptos, ejemplos, diferencias y escenarios antes de tomar un curso dictado por profesionales.

## Roadmap

1. **Guía personal**  
   Leer esta guía semanalmente y tomar notas.

2. **Curso dictado por profesionales**  
   Después de la guía, tomar un curso introductorio dictado por profesionales, como Udemy o una plataforma similar, evitando cursos Bridge si no se tiene ITIL 4.

3. **Practice exams**  
   Usar simulacros específicos de ITIL Foundation Version 5. El objetivo no es memorizar dumps, sino entender por qué una respuesta es correcta.

4. **ITIL V5 Web Flashcards**  
   Sitio web con flashcards que ayudarán a repasar lo esencial para ITIL V5 con lo aprendido durante esta guía y el curso. Under Construction.

5. **Examen oficial**  
   Agendar cuando pueda explicar los conceptos con ejemplos propios.

## Deploy con GitHub Pages

1. Crea un repositorio.
2. Sube estos archivos al root.
3. Ve a `Settings > Pages`.
4. Selecciona `Deploy from a branch`.
5. Selecciona `main` y `/root`.
6. Guarda.

URL esperada:

```txt
https://TU_USUARIO.github.io/itil-v5-study-guide/
```
